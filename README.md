# Estudo da Propriedade CSS: Display

Um projeto prático desenvolvido para compreender e visualizar na prática o comportamento dos diferentes valores da propriedade **`display`** no CSS.

---

## 🚀 Sobre o Projeto

Este repositório serve como um laboratório de testes e estudos para entender como os elementos HTML se comportam no layout da página através do CSS. O foco principal é dominar as nuances entre os comportamentos de exibição mais utilizados no desenvolvimento web moderno e tradicional.

### 📚 Conceitos Abordados
* **`display: none`**: Oculta completamente o elemento da página, removendo-o do fluxo visual.
* **`display: block`**: Ocupa toda a largura disponível e força uma quebra de linha antes e depois do elemento.
* **`display: inline`**: Ocupa apenas o espaço necessário pelo seu conteúdo e permite elementos lado a lado, sem aceitar propriedades de altura e largura (width/height).
* **`display: inline-block`**: Combina o melhor dos dois mundos: permite que os elementos fiquem lado a lado (como *inline*), mas aceita definições de largura, altura e margens (como *block*).
* **`display: flex` (Flexbox)**: Um modelo de layout unidimensional poderoso para distribuição de espaço e alinhamento de itens.

## 🧰 Linguagens e Tecnologias

As seguintes tecnologias foram utilizadas no desenvolvimento deste projeto:

* **CSS3**: Estilização visual e aplicação dos diferentes tipos de `display`.
